# Procedencia de la documentación

La documentación vigente es [README.md](README.md). SemantIAr publica un **recurso léxico-terminológico clínico del español rioplatense**, derivado de anotación, sin distribuir notas clínicas.

El documento histórico permanece en el [commit anterior](https://github.com/manwithbarba/semantiar-terminology-corpus/blob/bb36b7f7ebabf10c3f2642ef9cf5040366241f70/README_ORIGINAL.md). Sus rutas `public/` y `review/` describían el espacio de trabajo y no la estructura pública actual.

El original informó 14 parejas/7 muestras; el README de origen actualizado informó 15 parejas/15 muestras. La documentación vigente conserva la declaración más reciente, sin afirmar que verifica notas únicas o composición efectiva. Se reemplaza la clasificación automática gold/silver por procedencia y auditoría independiente. El porcentaje de asignación FAISS no se interpreta como exactitud.
